# 請求書PDFデザインリデザイン 設計ドキュメント

**Date:** 2026-03-19

## Goal

PDFプレビュー出力のデザインをSAKURA OSと同系統のモダン・スタイリッシュなデザインに刷新し、消えていた登録番号（T番号）を復活させる。

---

## 変更スコープ

- **対象**: `invoice.html` 内のPDFプレビュー専用CSS（`.pi-*` クラス群）と `buildInvoiceHTML()` 関数
- **対象外**: Webアプリ本体のフォーム・サイドバーUI

## セクション別仕様

### ① ヘッダー
- **トップバー**: `linear-gradient(135deg, #e91e63, #7c3aed)` 高さ8px
- **「請　求　書」タイトル**:
  - 左にグラデーション縦ライン（幅4px）
  - テキストをグラデーション（`-webkit-background-clip: text`）
  - フォント: Outfit 900 28px letter-spacing 8px
- **右側情報**: 請求対象月のみピンク太字、その他は現行維持

### ② 顧客／自社セクション
- **区切り線**: グラデーションライン（`#e91e63 → #7c3aed`）
- **顧客名**: 現行維持（太字大文字、下線）
- **自社側**: 登録番号を追加表示

### ③ 品目テーブル
- **ヘッダー行**: `linear-gradient(135deg, #e91e63, #7c3aed)` 背景 + 白文字
- **偶数行**: `rgba(233,30,99,0.04)` ティント
- **ボーダー色**: `#e0d0f0`

### ④ 合計フッター
- **合計セル**: `linear-gradient(135deg, #e91e63, #7c3aed)` 背景 + 白文字 + 白アイコン
- **税抜・消費税**: `#f8f6ff` 薄背景

### ⑤ 登録番号（バグ修正）
- 定数: `const COMPANY_REG_NUMBER = 'T9120001205370'`
- `buildInvoiceHTML()` の `pi-our-side` 内に表示
- `collectFormData()` からの動的取得は不要（固定値）
